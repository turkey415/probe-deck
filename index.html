Stop the browser warning

A self-signed certificate is encrypted like any other, but browsers warn because nobody vouches for it. Trust it once on each PC:
Windows (Chrome, Edge): download it, open the .crt, Install Certificate → Local Machine → Place in Trusted Root Certification Authorities.
Linux: sudo cp probe-01.crt /etc/pki/ca-trust/source/anchors/ && sudo update-ca-trust (Fedora/Nobara), then restart the browser.
Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
Check the SHA-256 fingerprint above matches what the browser shows before you trust it.
